canvas-helper · Edge 扩展 0.5.1
==========================================

安装一次
--------
1. 解压扩展 ZIP，保留解压后的文件夹。
2. 在 Edge 打开 edge://extensions，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择直接包含 manifest.json 的文件夹。

从旧版更新
----------
1. 将新版解压后的文件覆盖到原来加载的扩展文件夹。
2. 打开 edge://extensions，找到本扩展，点击“重新加载”。
3. 刷新 Canvas 课程页，关闭旧工作台，再点击扩展图标重新打开。

查看本学期课程
--------------
1. 登录 Canvas，停在 Dashboard 首页，点击浏览器工具栏中的扩展图标。
2. 插件自动打开课程清单，读取课程介绍并在后台逐门检查 Panopto 视频。
3. 用学期下拉框切换范围，用搜索框查找课程名称或编号。
4. 点击课程名称查看完整介绍，或从每门课程的快捷入口打开课程主页、视频列表。

宽屏右侧打开阅读面板，课程清单仍可切换；窄屏进入独立详情视图。
阅读面板顶部提供“返回课程”和上一门、下一门；键盘 Escape 可返回清单。
首页没有介绍时，尝试读取课程大纲；保留原文的标题、段落、列表和文字强调。
“有视频”表示已在列表或播放器中确认视频；“暂无视频”表示已确认列表为空。
“已找到入口”表示课程提供了 Panopto 入口，列表内容需进入后确认，可点击“视频列表”查看。
“未发现入口”与“读取失败”分开显示，读取失败可点击“重试这门课程”。
点击顶部“刷新”重新读取课程列表与内容；处理期间可点击“停止”。
点击“课程主页”或“视频列表”即可进入对应页面。

学期依据 Canvas 计算的有效选课状态与学校提供的课程/学期日期判断。
学校未提供足够日期时，默认显示 Dashboard 中的课程并提示；可手动切换学期。
检查期间保持原 Canvas Dashboard 和总览页打开。
视频状态通过后台请求读取；需要交互式进入的课程保留视频入口，由你点击查看。

批量下载讲座
--------
1. 登录 Canvas，打开课程的“Panopto Video”讲座列表。
2. 点击扩展图标。需要视频时，勾选“同时下载视频”。
3. 点击“一键扫描并下载”。开启视频时，先选一次 ZIP 保存位置，随后自动写入；
   仅下载转录稿时，完成后保存 ZIP。

下载期间保持课程页和工作台打开。
挑选讲座：先点“只扫描列表”，点击网格卡片的标题区域选择或取消，可多选。
也可使用“全选”，再点“下载选中”。

下载结果
--------
所有结果放在同一个 ZIP 的根目录：
• 每期一份 TXT 转录稿，包含标题、来源链接和转录文字。
• 勾选“同时下载视频”时，包含取得的视频文件。
• 一份“下载清单.csv”，统一记录转录稿和视频的文件、状态、原因及来源链接。

视频流式写入，支持 ZIP64 和超过 4 GB 的压缩包。
勾选视频后，某期没有字幕时仍会尝试下载其视频；未提供原生视频下载时，在清单中注明原因。

停止与重试
----------
开启视频时，点击“停止”会停止当前下载，并自动将已完成条目保存到同一个 ZIP。
点击“重试失败”继续更新这个 ZIP，跳过已经完成的视频。
ZIP 保存位置在工作台打开期间保留；继续或重试前请勿关闭或刷新工作台。
下载站点需要额外读取授权时，点击“重试失败”，Edge 会只询问当前实际站点的权限。

需要排查错误时，展开诊断区域并点击“复制诊断信息”。
仅下载转录稿时，可点“保存已有结果”保存；关闭或刷新工作台前先保存。
