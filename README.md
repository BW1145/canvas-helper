# canvas-helper

用于 Microsoft Edge 的 Canvas 课程总览与 Panopto 批量下载扩展，当前版本 **v0.4.1**。

## 功能

- 在 Canvas Dashboard 点击扩展，按网格查看课程名称、代码、学期和教师提供的首页介绍；首页没有介绍时尝试读取课程大纲。
- 当前学期同时参考 Canvas 计算的有效选课状态和明确日期，并支持手动切换；课程介绍默认显示全文，可手动收起。
- 在后台读取 Panopto 视频状态，区分有视频、暂无视频、已找到入口、未发现入口和读取失败。
- 扫描 Panopto 讲座列表，支持网格多选、全选和下载选中讲座。
- 批量保存 TXT 转录稿，可选同时下载视频；视频、转录稿和一份「下载清单.csv」统一放在同一个 ZIP 根目录。
- 视频流式写入，支持 ZIP64；停止后保存已完成条目，工作台保持打开时可重试失败项目。

## 安装与更新

1. 下载 Release 中的扩展 ZIP 并解压，或克隆本仓库。
2. 在 Edge 打开 `edge://extensions`，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择直接包含 `manifest.json` 的文件夹。
4. 更新时用新版覆盖扩展文件，点击扩展的「重新加载」，刷新 Canvas 并重新打开工作台。

扩展本身无需构建、Node.js 或额外依赖。

## 使用

**课程总览：** 登录 Canvas，在 Dashboard 点击扩展图标。课程介绍先显示，随后通过后台请求逐门检查 Panopto。检查期间保持 Dashboard 和总览页打开；可切换学期、收起介绍、打开课程或视频列表，也可停止或重新读取。

“有视频”和“暂无视频”来自列表接口的实际结果。学校要求交互式进入视频入口、重新登录，或暂未提供可后台读取的列表时，显示“已找到入口”，由你点击“视频列表”进入查看。课程日期不足时，范围明确显示为“Dashboard 上的课程”，也可手动选择具体学期。

**批量下载：** 打开课程的 Panopto 视频列表，点击扩展图标，再点「一键扫描并下载」。如需挑选讲座，先点「只扫描列表」，在网格中选择后点「下载选中」。

勾选「同时下载视频」时，先选择一次 ZIP 保存位置；仅下载转录稿时，完成后保存 ZIP。下载期间保持课程页和工作台打开。视频与对应 TXT 使用相同文件名前缀，结果和失败原因记录在清单中。无字幕讲座仍会尝试下载视频，具体取决于站点提供的下载能力。

点击「停止」保存已完成的视频下载结果；点击「重试失败」继续更新同一个 ZIP。继续或重试前保持工作台打开。仅下载转录稿时，也可用「保存已有结果」手动保存。

## 权限与本地文件

扩展沿用当前浏览器的登录状态，通过 `activeTab` 读取用户主动打开的 Canvas 页面，并使用 Panopto 站点权限扫描与下载。实际下载站点需要额外权限时，重试会请求该站点的读取授权。

账号凭据、浏览器会话、课程视频、转录稿及诊断信息应保存在本地；`.gitignore` 已列出常用排除规则。提交新文件前请检查暂存清单。

## 开发与验证

安装 Node.js 22+ 后，在仓库根目录运行：

```sh
npm test
```

测试覆盖课程与学期读取、Panopto 状态检测、讲座收集、网格选择、转录稿转换、统一 ZIP、视频传输、停止及重试。自动化测试使用模拟浏览器、网络和文件句柄；学校账号下的课程总览实机验证另行进行。版本附带的验证记录见 `VERIFICATION.txt`，详细操作见 `README.zh-CN.txt`。

安装 Playwright 及其 Chromium 后，可运行 `node courses.browser.test.cjs` 检查真实浏览器中的全文显示、学期筛选、后台状态读取与窄屏布局。可用环境变量 `CANVAS_HELPER_BROWSER_CHANNEL=msedge` 选择本机 Edge；测试使用独立浏览器和模拟课程数据。

接口依据：[Canvas 课程与选课状态](https://developerdocs.instructure.com/services/canvas/resources/courses)、[Panopto REST API](https://demo.hosted.panopto.com/Panopto/api/docs/index.html)。
